## Sobre o projeto

**Nebula Quest** é a landing page de um jogo de plataforma espacial que não existe — mas que poderia. O projeto foi feito como um exercício rápido de estilização, explorando uma estética 8-bit/16-bit com cores neon, tipografia pixelada e pequenas animações em CSS puro, sem depender de nenhum framework ou biblioteca.

Diferente dos outros projetos do meu portfólio, este é intencionalmente simples: um único arquivo HTML, sem build, sem dependências — só HTML e CSS bem trabalhados.

## Destaques visuais

- **Tipografia pixelada** (`Press Start 2P` e `VT323`, via Google Fonts)
- **Textos e bordas com efeito neon**, usando `text-shadow` e `box-shadow`
- **Fundo estrelado animado**, com `@keyframes` em CSS puro
- **Efeito de scanlines**, simulando uma tela CRT antiga
- **Sprites pixelados em SVG**, com animação de flutuação
- **"Screenshots" gerados só com CSS** (gradientes e padrões), sem nenhuma imagem externa

## Tecnologias

| Tecnologia | Uso |
|---|---|
| HTML5 | Estrutura da página |
| CSS3 | Toda a estilização, animações e efeitos visuais, sem framework |
| Google Fonts | Tipografia pixelada (`Press Start 2P`, `VT323`) |

## Rodando localmente

Não precisa de instalação nem de servidor — é um único arquivo:

```bash
git clone https://github.com/TiagoAlmeida13/nebula-quest.git
cd nebula-quest
```

Abra o arquivo `index.html` diretamente no navegador.
